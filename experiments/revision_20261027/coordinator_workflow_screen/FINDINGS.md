# 依赖链工作流：协调端独立机制筛选

日期：2026-10-27。状态：真实运行的本地 EVM 筛选；不是原生 NEAR、Avalanche 或 Polkadot 性能测试。

## 可展示的因果差异

每个旅程包含共同的四笔边界操作（迁入 burn/mint、迁出 burn/mint），中间执行两轮有状态多合约依赖链。各路径的最终输出、已消费执行额度、最终余额和未完成迁移均由断言核对。部署、创建池与预置资金不计入旅程时间或 gas。

## 解释与可证伪条件

在没有饱和或失败、每个依赖确认阶段跨一个区块的受控模型内，本地路径需要 4+θ 个阶段，异步路径需要 4+θd 个阶段。差异来自局部组合省去中间确认阶段；并非重新测出了 DAS 对所有 SOTA 的独有优势。

当前只验证顺利执行时相同最终业务结果；本地 EVM 内部调用与异步阶段提交的故障原子性不同，尚未对齐。不得将本结果描述为完全同语义的协议性能优越。

反例与适用边界：深度为 1 时没有阶段数优势；其他平台迁入后也在同一执行域组合调用时没有 DAS 独有优势；对照可合法使用同接收者批处理或更强的当前运行时功能时必须重新建模。若实际区块/最终性时间不同、迁移证明更贵、本地执行饱和，领先可能消失甚至反转。

## 模型边界

- 这是单个本地 Anvil 上的执行路径筛选，并非独立分片共识、跨链网络或原生 NEAR 测试。
- 异步阶段由驱动在上一阶段确认后推进；未加入额外 sleep 或虚构网络延迟，但该规则本身是显式模型假设，须由原生 runtime 验证。
- 业务为有状态 hash 依赖链，不是实际 DEX/借贷应用；边界适配器使用测试账本单位，不实现认证、真实资产托管或最终性证明，不可用于安全结论。
- EVM gas 只比较同一 EVM 上的两种实现路径，不能当作 NEAR gas 或各平台手续费。
- 每个执行组在一个同样资源预算的本地 EVM 中完成；没有测饱和吞吐。
- 所有负向对照与原始逐交易数据均保留。

## 进一步验证

3. 加入最佳允许批处理、同域执行、独立业务并行和本地执行饱和的反例。

## 复现

环境：Python + web3 7.16.0 + py-solc-x，Solidity 0.8.24，优化开启 runs=200，Anvil 1.8.6。运行脚本仅启动和终止自己创建的随机本机端口节点。

```sh
ANVIL_BIN=/path/to/anvil python run_screen.py --block-seconds 1 --depths 1,4,8 --rounds 2 --repeats 3
ANVIL_BIN=/path/to/anvil python run_screen.py --block-seconds 12 --depths 4 --rounds 2 --repeats 3
```
